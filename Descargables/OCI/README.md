## Tips para el Examen

### Formato del Examen
- **Duración**: 90 minutos (Foundations), 60-90 min (otros)
- **Preguntas**: 45-50 preguntas
- **Passing score**: 68-70%
- **Formato**: Multiple choice, multiple select
- **Precio**: Varía según región (~$150-200 USD)

### Temas Clave (Foundations)
1. **Cloud Concepts** (10%)
2. **Core OCI Services** (30%)
3. **Compute** (15%)
4. **Networking** (15%)
5. **Storage** (15%)
6. **Security** (15%)

### Temas Clave (AI Foundations)
1. **AI Concepts** (20%)
2. **OCI AI Services** (40%)
3. **Machine Learning** (20%)
4. **Gen AI** (20%)

### Conceptos Importantes
- **Availability Domain** vs **Fault Domain**
- **Compartments** y jerarquía
- **IAM Policies** sintaxis
- **VCN** arquitectura
- **Load Balancer** tipos
- **Block Volume** vs **Object Storage**
- **Autonomous Database** características
- **AI Services** capacidades específicas
